# Аналитический дашборд: метрики сервисов и трекер инцидентов

Интерактивный дашборд в Power BI для анализа вовлеченности пользователей и мониторинга технических сбоев.

## 📊 Структура проекта
*   `data/` — исходные CSV-файлы с данными.
*   `reports/` — готовый файл дашборда (`bi_validation_dept.pbix`).
*   `scripts/` — Python-скрипт, с помощью которого подготовлен датасет.

## 🛠 Ключевые метрики в отчете
*   **Продуктовые**: анализ ежедневной и ежемесячной активности (DAU, MAU, Sticky Factor).
*   **Операционные**: учет сэкономленного времени за счет автоматизации.
*   **Технические**: мониторинг инцидентов (ошибки API, доступы) и критических рисков.
